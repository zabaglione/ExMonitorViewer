# ExMonitorViewer v0.1.0

Windows 向けの拡張モニター表示アプリの初回リリースです。

- DXGI Desktop Duplication と Direct3D 11 を使い、GPU 内で画面をコピー・拡大描画します。
- 60 FPS 上限を既定値とし、30 FPS と無制限にも切り替えられます。
- メニューまたは数字キーでキャプチャ画面を選択できます。
- ウィンドウの縦横比維持、縦向き画面、F11 全画面表示に対応します。
- Capture FPS と Present submit FPS を別々に表示します。

実測値は同梱の `BENCHMARK.txt` を参照してください。60 FPS は元画面の更新頻度や GPU、デスクトップ合成などに左右され、すべての環境で保証される値ではありません。保護された画面、HDR 色変換、マウスカーソル合成、複数 GPU 間コピーには対応していません。

## 性能計測

RTX 3090 Ti 搭載環境で、動き続けるテストパターンを `\\.\DISPLAY2` から FHD でキャプチャし、FHD クライアント領域へ表示した20.008秒の計測では、Capture が59.676 FPS（1194更新）、Present submit が59.776 FPS（1196回）でした。Present submit は実際にモニターへ表示されたフレーム数を保証しません。計測条件とカウンターは同梱の `BENCHMARK.txt` に記載しています。
