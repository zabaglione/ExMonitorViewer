# ExMonitorViewer v0.1.2

## 変更点

- ウィンドウの位置・サイズ、選択画面、FPS上限、最前面表示を正常終了時に保存し、次回の通常起動時に復元します。
- 設定は `%LOCALAPPDATA%\ExMonitorViewer\settings.json` に保存するため、アプリの展開先を変えても引き継がれます。
- `--settings-file PATH` で設定ファイルを指定できます。`--monitor`、`--fps`、`--size` の明示指定は保存値より優先されます。
- `--benchmark`、`--list-monitors`、`--help` は通常設定を読み書きしません。
- 不正または利用できない設定は警告を出して安全な既定値で起動します。変更なしで終了した場合、不正な設定ファイルは保全します。画面構成が変わった場合は、ウィンドウを操作できる表示範囲に配置します。
- 最小化中やF11全画面表示中の一時的なサイズは保存せず、通常サイズと最大化状態を記録します。位置とサイズは物理ピクセルで保存するため、異なるDPIの画面では論理サイズが一致しない場合があります。

## 検証

- Rustテスト14件、警告をエラー扱いにしたClippy、リリースビルドが成功しました。
- 同梱の性能レポートはv0.1.1の参考測定値です。v0.1.2では性能を再測定していません。
- 設定の保存と再起動後の復元は、v0.1.2で手動確認していません。
