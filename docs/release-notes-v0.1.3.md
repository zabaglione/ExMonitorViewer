# ExMonitorViewer v0.1.3

## 追加

- `Fit window to image` メニュー項目と `F` キーで、現在の表示サイズを基準にウィンドウを映像と同じ縦横比へ調整できます。表示後も手動で自由にリサイズできます。
- `Scale` メニューに 25%、50%、75%、100%、125%、150%、200% を追加しました。100% は映像の原寸です。作業領域に収まらない倍率は縦横比を保って調整し、実倍率をタイトルバーに表示します。
- Fit と Scale は最大化または全画面表示からも選べます。位置は作業領域内に調整し、最前面設定を維持します。サイズは既存の設定ファイルに保存します。

## 描画

- GPU 描画経路とカーソル合成を維持しています。Fit と Scale はウィンドウのクライアントサイズを変更し、映像に黒帯が入らない縦横比へ合わせます。

## 実機確認

- 選択画面3、FPS 30、最前面表示、通常ウィンドウの位置・サイズを保存し、再起動後に各設定とウィンドウ位置・サイズが復元することを確認しました。
- 最大化したまま終了した場合も通常ウィンドウの位置・サイズを保持し、再起動後の復元操作で戻ることを確認しました。最大化時の位置・サイズが通常位置・サイズへ誤保存される問題も修正しました。
- 全画面表示中に終了しても、全画面サイズを通常ウィンドウの保存サイズへ書き込まないことを確認しました。
- FHD映像で `F` を押すと、800x600のクライアント領域が800x450になり黒帯がなくなること、最前面状態と位置が維持されることを確認しました。
- FHD映像の50%（960x540）と25%（480x270）を選び、ウィンドウサイズが保存されて再起動後に復元されることを確認しました。再起動後は50%項目が選択表示されました。
- 狭いウィンドウでメニューが複数行になる場合も、Fit後のクライアント領域が映像の縦横比と一致することを確認しました。
- RTX 3090 Ti搭載PCでFHDキャプチャ・FHDクライアント領域を20.003秒測定し、Capture 59.992 FPS、Present submit 59.992 FPS（1200フレーム）でした。GPUカーソル合成fixtureは1回の形状アップロードで1200回すべてのPresentにカーソルを合成しました。
- ベンチマーク実行前後で設定ファイルのSHA256が同じで、設定が変更されないことを確認しました。
- `cargo test --offline` の16件と `cargo clippy --offline -- -D warnings` が通過しました。
